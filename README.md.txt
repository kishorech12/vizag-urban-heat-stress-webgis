# 🔥 Vizag Urban Heat Stress WebGIS

A ward-level WebGIS platform to analyze Urban Heat Stress in Visakhapatnam using satellite-derived LST and NDVI.

## Features
- Heat Stress Index (HSI) mapping
- Top 10 hottest wards
- Interactive Leaflet map
- FastAPI backend with PostGIS

## Tech Stack
- Leaflet.js
- FastAPI
- PostGIS
- GeoPandas
